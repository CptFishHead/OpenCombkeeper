# Правила OpenCombkeeper

- Общаться с пользователем по-русски.
- Цель проекта — получить уникальные виды сот и, при выбранном режиме, сохранить лучших производителей.
- Принцессы учитываются как линии, а не по NBT конкретного предмета.
- Не угадывать результат физической операции и не повторять неопределённый перенос.
- Однозначные мутации можно автоматизировать; неоднозначные требуют продвинутого мутатрона и задачи игроку.
- `restore` через чужой вид не реализовывать.
- Серверные данные имеют приоритет над клиентским каталогом, если их происхождение явно отмечено.
- Соблюдать KISS/YAGNI. Оптимизировать только метрики, которые показаны пользователю.
- Перед коммитом запускать полный набор тестов и `git diff --check`.
- Не использовать force push.
