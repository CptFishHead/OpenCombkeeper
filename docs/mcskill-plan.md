# Расчёт для установленной сборки McSkill

Исходные данные: Forestry 5.8.2.422, Binnie Mods 2.5.1.203 и Gendustry
1.6.5.8 из клиентской сборки HiTech 1.12.2. Стартовыми считаются 14 видов,
получаемых не через зарегистрированные мутации: шесть обычных ульевых Forestry,
Steadfast, Valiant, Monastic, Ended и четыре ульевых Extra Bees.

Режим `best`, вероятность наблюдения продукта 99%:

| Показатель | Значение |
|---|---:|
| Уникальные виды сот | 105 |
| Достижимые виды сот | 105 |
| Выбранные производители | 99 |
| Безопасное число линий принцесс | 114 |
| Мутационные переходы линий | 208 |
| Критическая глубина графа | 13 |
| Ручные задачи | 69 |

114 — не теоретический абсолютный минимум для произвольного гиперграфа, а
детерминированная безопасная потребность выбранного плана. Она учитывает отдельные
линии для производителей и источников дронов, но не включает потери от Genetic
Waste. Перед игровым запуском план необходимо пересчитать по фактическому числу
стартовых принцесс и сверить рецепты с серверным каталогом Forestry.
